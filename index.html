Market settings

MACD / DIF / DEA filters

Select the MACD timeframes you want scanned. DIF is the MACD line (EMA 12 minus EMA 26). DEA is the 9-period signal line. Enter a minimum or maximum to activate that value filter. Leave both blank if you only want the timeframe scanned without a DIF or DEA value restriction. All MACD calculations use completed candles. The 24h timeframe uses 1-day candles.

DIF and DEA are raw price-based MACD values, not RSI-style standardized values. Their numerical scale varies between coins.

Optional RSI filters

Select RSI timeframes independently. Every enabled RSI condition must pass. RSI is also displayed for the corresponding MACD timeframe where available.

Optional Supertrend timeframes

Select one or more Supertrend timeframes. There is no bullish/bearish direction dropdown. The scanner reads the direction automatically and sends bullish signals to the Bullish column and bearish signals to the Bearish column. Supertrend uses ATR(10), multiplier 3. If multiple Supertrend timeframes are selected, they must agree on direction for a result to appear.
