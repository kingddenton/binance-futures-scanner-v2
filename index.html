Market settings

MACD filters

Standard MACD 12/26/9. Every selected timeframe must agree. Bullish requires both DEA and histogram above zero. Bearish requires both below zero. Zero or disagreement excludes the coin.

Optional RSI filters

All enabled RSI filters must pass. RSI is calculated using completed candles.

Optional Supertrend filters

ATR 10, multiplier 3. Every selected timeframe must agree with the MACD direction.

Optional Open Interest filter

The same OI settings apply to Bullish and Bearish results. Positive OI change qualifies for Bullish; negative OI change qualifies for Bearish.

The OI percentage threshold uses the selected OI timeframe above. The minimum OI amount always uses the 5-minute OI change in USDT. Bullish requires positive 5-minute OI change; bearish requires negative 5-minute OI change. The minimum 5-minute OI threshold is adjustable and enabled by default when OI filtering is on.

MACD crossover settings
