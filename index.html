Market settings

MACD filters

Standard MACD 12/26/9. Every selected timeframe must agree. Bullish requires both DEA and histogram above zero. Bearish requires both below zero. Zero or disagreement excludes the coin.

Optional RSI filters

All enabled RSI filters must pass. RSI is calculated using completed candles.

Optional Supertrend filters

ATR 10, multiplier 3. Every selected timeframe must agree with the MACD direction.

Optional Open Interest filter

Each enabled OI window is calculated from Binance 5-minute OI history. 5m = one interval, 10m = two intervals, 15m = three intervals. Dollar and percentage thresholds are independently adjustable. Bullish requires positive OI change; Bearish requires negative OI change.

10-minute OI is derived from two 5-minute intervals because Binance has no native 10-minute OI period. All enabled thresholds are checked against the direction of the MACD signal.

Optional Volume Change filters

Compare the latest two completed Binance candles using USDT quote volume. Volume expansion confirms participation; it does not determine direction.

If both volume filters are enabled, both must pass. This is candle-to-candle volume change, not a long-term average.

MACD crossover settings

Detect DIF crossing DEA on a completed candle. This runs independently from the Bullish/Bearish momentum filters.
