Market settings

MACD timeframes

Select the timeframes to scan. Standard MACD settings are 12, 26, 9. For every selected timeframe, both the histogram and DEA must be positive for a bullish result, or both negative for a bearish result. Zero or disagreement excludes the coin. DIF is displayed only.

Optional RSI filters

All enabled RSI filters must pass. RSI uses the selected period and completed candles.

Optional Supertrend filters

Supertrend uses ATR(10), multiplier 3. All selected Supertrend timeframes must agree with each other and with the MACD/DEA direction.
